# 外送風雲：開發計劃（`/delivery/`）

外送平台管理遊戲。玩家係平台嘅「中央調度」：喺真實地圖上調配外送員，好似分佈兵力咁，邊度多餐廳、邊個時段多單，就派多啲人去。成功送單，平台抽成賺錢。爆單時可以加錢、停單，或者自己落場送，落場就用返泊車地獄嘅機車／汽車泊車玩法。

> 遊戲名、品牌、顏色全部自己設計。唔可以用 foodpanda、Uber Eats、Lalamove 嘅名、logo 或者標誌色。下面提到佢哋，只係講玩法類型。

---

## 0. 開工前必讀

1. 先讀 repo 根目錄嘅 `PROJECT.md`，了解 `hk/`、`tw/` 兩個泊車遊戲點寫。
2. 跟用戶嘅「減 Code」六步，次序唔可以亂：
   1. 呢個功能真係需要？
   2. 項目入面係咪已經有？（尤其泊車部分：**唔好重寫，重用 `hk/`、`tw/`**）
   3. 優先用標準庫
   4. 優先用瀏覽器、資料庫、作業系統原生功能
   5. 優先用現成套件
   6. 最後先自己寫，而且寫最少、啱用嘅 code
3. 同 repo 其他遊戲一樣：**冇 build step**，套件由 CDN 載入，進度儲 `localStorage`。
4. 每個頁面都要有 favicon 同分享圖（og:image），網址格式跟現有頁面：`https://fiveathree.github.io/pkparking/delivery/`。
5. 畫面盡量一個 screen 裝晒，唔好要上下或者左右碌（手機同電腦都係）。
6. 原本 `hk/`、`tw/` 嘅玩法同進度唔可以受影響。

## 2. 技術選擇

| 需要 | 用咩 | 備註 |
|---|---|---|
| 地圖顯示 | Leaflet 1.9（CDN） | 底圖用 OpenStreetMap tiles，**一定要顯示 © OpenStreetMap contributors**；揀暗色風格可以用 CSS filter 壓暗，唔使另搵圖源 |
| 餐廳、商業區、住宅位置 | Overpass API | 一次過抓 `amenity=restaurant/fast_food/cafe`、`shop=supermarket/convenience`、`building=residential/apartments` |
| 道路 | Overpass API 抓 `highway=*` | 自己砌道路圖（節點＋邊） |
| 行車路線 | 道路圖上行 A*，可以用現成套件 `ngraph.graph` + `ngraph.path`（CDN） | **唔好**每張單都 call 外部路線 API（OSRM demo 有限流） |
| 快取 | `localStorage`（地圖資料用 IndexedDB 如果太大） | Overpass 結果每個城市快取 7 日，唔好每次開都重新抓 |
| 泊車小遊戲 | 現有 `hk/`、`tw/`，用 `<iframe>` 載入 | 見第 6 節 |
| 3D | 外送遊戲本身唔使 3D | 泊車部分已經係 three.js |

### 城市（開局揀）
| 城市 | 中心區 | 預設車種 |
|---|---|---|
| 高雄 | 新堀江／中央公園一帶 | 機車 |
| 台北 | 西門町／中山一帶 | 機車 |
| 香港 | 旺角／油麻地一帶 | 汽車＋電單車 |

每個城市第一區約 2 km × 2 km；之後擴張再抓相鄰區。Overpass 抓唔到就用快取；冇快取就顯示「地圖載入失敗，重試」，唔好白畫面。

## 3. 核心玩法：調度中心

### 3.1 時間
- 遊戲時間：1 日 = 現實約 8 分鐘（可以 ×1 / ×2 / ×4 / 暫停）。
- 每日 06:00 開始，凌晨 02:00 收工，之後出「日結」畫面。

### 3.2 單量從邊度嚟
每間餐廳有「出單率」，由以下相乘：
- **時段曲線**：早餐 07–09 小高峰、午餐 11:30–13:30 大高峰、下午茶 15–16 小高峰、晚餐 17:30–20:30 最大高峰、宵夜 22–01 中高峰。
- **餐廳類型**：fast_food 高、cafe 下午高、restaurant 晚餐高。
- **天氣事件**：落雨單量 +40%，外送員速度 −20%；颱風日更誇張（隨機觸發，有預告）。
- **平台評分**：評分低，單量跌。
- 送餐目的地：隨機揀附近住宅／寫字樓，距離 0.3–3 km。

地圖上用 **熱力圖** 顯示即時單量（可以用 Leaflet.heat 套件），同顯示外送員分佈，一眼睇到「邊度兵力唔夠」。

### 3.3 外送員
- 狀態：休息／等單／去餐廳／等餐／送緊／返回。地圖上用唔同顏色點顯示。
- 屬性：速度、可靠度（會唔會甩單）、體力（做太耐要休息）。
- **請人**：每日開工前喺「人力市場」請，有日薪或者純抽成兩種。
- **調配（核心操作）**：
  - 將地圖分成區（用六角格或者方格，約 400 m 一格）。
  - 玩家拖外送員去某一格「駐守」，或者畫一個範圍，設定「呢區最少 X 人」。
  - 系統自動派單：搵最近又得閒嘅外送員；玩家可以手動改派。
- 外送員路線跟道路圖行，地圖上見到佢哋郁。

### 3.4 收入同支出
每張單：
- 食物價錢（例如 NT$120–600 / HK$50–200）
- 平台抽成 % （玩家可以調，抽得太高會有餐廳退出平台）
- 運費（客付）
- 外送員每單收入（平台付）
- 遲到賠償、取消單

日結顯示：完成單數、準時率、收入、支出、淨利、評分變化。用一張小表就得，唔好整複雜報表。

### 3.5 評分
- 準時送到：評分升
- 遲到：跌；遲太耐客人取消：大跌
- 停單：輕微跌（比遲到好）

## 4. 爆單處理（三個選擇）

當某區「等緊冇人接嘅單」超過門檻，畫面閃紅提示「爆單」，玩家揀：

1. **加錢（Surge）**：該區每單加獎金，吸引「散工外送員」上線（臨時出現、做完就走），但每單利潤變薄。可以揀加幾多（+20% / +50% / +100%）。
2. **停單**：該區暫停接新單 N 分鐘。冇收入，評分輕微跌，但唔會再積遲到。
3. **親自出馬**：玩家自己接一張單（或者一條路上順路兩張），進入「自己送」流程（見第 5 節）。自己送嗰陣，調度中心時間減慢到 ×0.25，但唔停，返嚟可能已經有其他問題。

---

## 5. 親自出馬流程

1. **路線段（地圖上）**：喺 Leaflet 地圖上，玩家用方向鍵／搖桿揀路口轉邊條路（路口先需要揀，直路自動行）。路上有隨機事件：紅燈、塞車、落雨。目標係快過系統預計時間。唔好整 3D 開車，保持簡單。
2. **泊車段（重用泊車地獄）**：到目的地，彈出泊車挑戰：
   - 外送（機車）→ `tw/` 機車格地獄
   - 叫車／送件（汽車）→ `hk/` 窄位泊車王
   - 難度按目的地類型：住宅區易、夜市／商場／舊區難。
3. **交收**：泊車結果影響：
   - 用時加落總送餐時間
   - 推冧車（機車）／花痕（汽車）扣貼士，太多會被投訴
   - 三星泊車有額外貼士
4. 返回調度中心。

## 6. 泊車挑戰模式（改 `hk/`、`tw/`，越少改越好）

**用 iframe + URL 參數 + `postMessage`，唔好將 800 行嘅泊車檔案拆成模組。** 同一個網址底下，唔會有跨域問題。

### 入口參數
```
tw/?challenge=1&level=2&par=60
hk/?challenge=1&level=0&par=45
```
- `challenge=1`：挑戰模式
- `level`：用 `LEVELS` 入面第幾關（0 起計）
- `par`：限時（秒），可以唔傳，用關卡預設

### 挑戰模式行為
- 跳過選單，直接開嗰關，開頭提示加一句「送餐中：泊好車先交到貨」。
- **唔寫入原本嘅進度**（`zwp-progress` / `jcg-progress` 唔郁）。
- 完成或者失敗時：
  ```js
  parent.postMessage({ type: 'parking-result', ok: true, time: 38.2, stars: 3, damage: 0 }, location.origin);
  ```
  - 汽車：`damage` = 花痕數
  - 機車：`damage` = 推冧架數 + 阻人架數
- 加一個「放棄」掣：送 `ok:false`，當遲到處理。
- 唔係 `challenge=1` 嘅時候，一切照舊。

### 外送遊戲一邊
- 開一個全螢幕 `<iframe>`，監聽 `message`，**要檢查 `event.origin === location.origin` 同 `type === 'parking-result'`**，收到就關 iframe、計結果。

### 日後可以加（第一版唔做）
- `level=gen&seed=123`：按種子隨機生成關卡，咁每次泊車都唔同。

## 7. 擴充模式：叫車同送件（第二階段）

第一版做好外送之後先做。完成一定日數或者賺夠錢解鎖。

### 7.1 叫車模式（Uber 類）
- 乘客喺地圖上隨機出現（高峰：返工、放工、深夜酒吧區）。
- 司機（汽車）調配邏輯同外送員一樣，但冇「去餐廳等餐」一段：接客 → 送去目的地。
- 收入按距離＋時間計，有「動態加價」（同爆單加錢同一套機制）。
- 親自出馬：泊車段用 `hk/`（落客位、路邊平排）。

### 7.2 送件模式（Lalamove 類）
- 貨件有大細：細件（機車）、中件（私家車）、大件（貨van，第一版可以當汽車）。
- 可以預約（例如 2 個鐘後取件），玩家要提前安排車。
- 親自出馬：泊車段用 `hk/`；大件可以用最難嗰幾關（工廈窄彎、地獄格）。

三個模式共用同一班人、同一張地圖、同一個錢包；玩家要決定人力點分配。

## 9. 儲存

- `localStorage` key：`wsfy-save`（錢、評分、外送員、已解鎖區域同模式、日數）。
- 每日日結自動儲存一次。
- 地圖資料快取同存檔分開 key：`wsfy-map-<城市>`。

## 11. 注意

- Overpass API 係免費公共服務：每個城市只抓一次再快取，唔好開一次抓一次，唔好喺遊戲運行中不停抓。
- OSM 底圖要有版權標示，唔好 hotlink 到用量大到違反 OSM tile 使用政策；如果日後玩家多，改用其他圖源。
- 冇後端、冇登入、冇付款，唔收集任何個人資料。
