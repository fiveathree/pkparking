# 泊車地獄

主頁（根目錄 `index.html`）揀香港版或者台灣版。

## 香港版：窄位泊車王（`/hk/`）

3D 香港式地庫窄位泊車。右軚自動波，由 B1 一路落到 B6 地獄格。鏡頭有俯視、追蹤、司機視角；司機視角入 R 波會出倒車鏡頭，拖畫面可以四圍望。

- B1 午夜地庫：車頭直入
- B2 倒泊入格：倒泊，車頭向外
- B3 柱位夾縫：車位口有柱
- B4 路邊平排：平排泊車
- B5 工廈窄彎：4.5 米窄路加 90 度彎
- B6 地獄格：2.3 米窄格，柱位，倒泊

單一檔案 `hk/index.html`，冇 build step，直接開或者用 GitHub Pages 放上網。

鍵盤：←/→ 扭軚、C 回正、↑ 油、↓/空格 煞車、Q 換 R、E 換 D、P 泊 P、V 換鏡頭（俯視／追蹤／司機）。

## 台灣版：機車格地獄（`/tw/`）

3D 台灣騎樓機車格。停定向後拉搖桿可以用腳踩倒後，窄到唔得就落車手推；行到車頭撳「推車頭」，行到車尾撳「拉車尾」擺位。推冧人哋架車會扣分，會骨牌式冧埋隔籬架。

五關：騎樓入門、車頭向外、借位擺正、夜市口、捷運站地獄。

鍵盤：WASD／方向鍵移動、F 上落車、E 推車／放手、V 換鏡頭（街景／俯視／主視角）、R 重來。主視角下搖桿上下係前後、左右係轉彎，拖畫面可以四圍望。
